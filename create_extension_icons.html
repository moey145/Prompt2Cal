📅 Prompt2Cal Extension Icon Generator

🎨 How to Create Icons

This tool will help you create the required icon files for your Chrome extension. The icons use a calendar emoji (📅) with a purple gradient background.

  1. Click the "Generate Icons" button below
  2. Download each icon file (16px, 32px, 48px, 128px)
  3. Save them in the chrome-extension/icons/ folder
  4. Name them: icon16.png, icon32.png, icon48.png, icon128.png

📁 File Structure

After downloading, your chrome-extension/icons/ folder should look like this:

chrome-extension/
├── icons/
│   ├── icon16.png    ← 16×16 pixels
│   ├── icon32.png    ← 32×32 pixels
│   ├── icon48.png    ← 48×48 pixels
│   └── icon128.png   ← 128×128 pixels
├── manifest.json
├── popup.html
└── ... other files

🚀 Alternative: Use Any Image

If you prefer, you can use any image as your extension icon:

  1. Find any 128×128 PNG image
  2. Copy it 4 times and rename to the required sizes
  3. Place them in the chrome-extension/icons/ folder
  4. The extension will work perfectly with any icons!
