# Chrome Web Store Listing Information

## Description (for Store Listing)

Prompt2Cal is an AI-powered Chrome extension that instantly converts natural language text into Google Calendar events. Simply describe your event in everyday language, and Prompt2Cal intelligently parses the details to create calendar entries with the correct date, time, location, and attendees.

### Key Features:

✨ **Natural Language Processing** - Type events like "Team meeting tomorrow at 2pm" or "Coffee with Sarah next Friday at 3pm" and let AI do the parsing

📅 **Google Calendar Integration** - Seamlessly create events directly in your Google Calendar with automatic conflict detection

🎯 **Smart Event Parsing** - Automatically extracts:

- Date and time (supports relative dates like "tomorrow", "next week", etc.)
- Event titles and descriptions
- Locations and attendees
- Recurring event patterns ("Every Monday at 9am")

🔍 **Conflict Detection** - Automatically checks for scheduling conflicts before creating events

🎤 **Voice Input** - Use voice recognition to speak your events naturally

📝 **Text Selection** - Select text on any webpage and create events with one click

⚡ **Multiple Events** - Create multiple events from a single input (e.g., "Meeting Monday at 2pm. Lunch Tuesday at 12pm")

🌙 **Dark Mode** - Beautiful dark mode support for comfortable use

### How It Works:

1. Click the Prompt2Cal icon in your browser
2. Type or speak your event description in natural language
3. Review the parsed event details
4. Click "Create Event" to add it to your Google Calendar

### Use Cases:

- Quickly schedule meetings from email threads
- Create events from text messages or notes
- Plan your week by describing multiple events at once
- Set up recurring events with simple phrases
- Add events while browsing websites

### Privacy & Security:

- All data is processed securely through our backend service
- Google Calendar access requires your explicit permission
- Your calendar data is never stored on our servers
- Full privacy policy available at: https://moey145.github.io/Prompt2Cal/privacy-policy.html

### Getting Started:

1. Install Prompt2Cal from the Chrome Web Store
2. Click the extension icon
3. Connect your Google Calendar account
4. Start creating events in natural language!

Transform the way you manage your calendar. No more clicking through multiple fields - just describe your event and let Prompt2Cal handle the rest.
